# Descargas REFER

Plantillas oficiales para autores de **REFER Revista Ferroviaria** (IPN, UPIIP).

Página de descargas: <https://refer-upiip.github.io/descargas/>

## Organización

```
descargas/
├── index.html                 página de descargas (GitHub Pages)
├── README.md                  este archivo
├── .nojekyll                  publica los archivos tal cual
├── assets/img/                logos REFER, IPN y UPIIP
└── plantillas/
    ├── articulo/
    │   ├── plantilla_articulo_refer.docx        Word
    │   ├── plantilla_articulo_refer.odt         LibreOffice
    │   ├── plantilla_articulo_refer_latex.zip   LaTeX (tex, bib, img)
    │   └── plantilla_articulo_refer.pdf         vista previa
    └── resena/
        ├── plantilla_resena_refer.docx
        ├── plantilla_resena_refer.odt
        ├── plantilla_resena_refer_latex.zip
        └── plantilla_resena_refer.pdf
```

## Reglas

1. Nombres en minúsculas, sin acentos ni espacios: `plantilla_<tipo>_refer.<ext>`.
2. Para actualizar una plantilla se reemplaza el archivo **con el mismo nombre**; así el enlace no cambia.
   El historial de versiones queda en Git (pestaña *Commits*).
3. Todo lo que está en este repositorio es público. No subir manuscritos, dictámenes ni datos personales.
4. Cada archivo debe pesar menos de 100 MB.
